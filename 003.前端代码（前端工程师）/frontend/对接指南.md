
## 启动方式

### 1. 启动后端
```bash
cd backend
npm install
cp .env.example .env
# 编辑 .env 配置数据库
npm run dev
```

### 2. 启动前端（需要 Web 服务器）
```bash
# 方法1: 使用 http-server
npx http-server -p 8080

# 方法2: 使用 VSCode Live Server 插件

# 方法3: 直接打开（部分功能受限）
# 直接双击 index.html
```

### 3. 访问地址
- 前端: http://localhost:8080/frontend/login.html
- 后端 API: http://localhost:3000

## 前端 API 使用示例

```javascript
// 登录
const res = await API.Auth.login({ username, password });
API.saveAuth(res.data.token, res.data.user);

// 获取收支列表
const res = await API.Transaction.getList({ page: 1, pageSize: 20 });
const { list, pagination } = res.data;

// 创建记录
await API.Transaction.create({
  type: 1,           // 1=支出, 2=收入
  amount: 100.00,
  categoryId: 1,
  date: '2024-10-08',
  paymentMethod: 2,   // 支付方式
  remark: '备注'
});

// 月度统计
const stats = await API.Transaction.getMonthlyStats('2024-10');
// stats.totalIncome, stats.totalExpense, stats.netProfit
// stats.expenseByCategory, stats.incomeByCategory
```

## 字段说明

### 收支类型 (type)
- `1` - 支出
- `2` - 收入

### 支付方式 (payment_method)
- `1` - 现金
- `2` - 微信支付
- `3` - 支付宝
- `4` - 银行卡
- `5` - 其他

### 对方类型 (counterparty_type)
- `1` - 客户
- `2` - 供应商
- `3` - 其他

### 记录状态 (status)
- `1` - 已支付/已收讫
- `2` - 挂账/待收/待付

## 常见问题

### 1. CORS 跨域错误
确保后端 `.env` 中配置了正确的 `CORS_ORIGIN`：
```env
CORS_ORIGIN=http://localhost:8080
```

### 2. Token 过期
前端 API 会自动检测 401 响应并跳转登录页

### 3. 数据不更新
检查浏览器控制台是否有错误，确保后端数据库连接正常
