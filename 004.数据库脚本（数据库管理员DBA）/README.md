## 业务概述

轻记账是一款面向个人和小型商户的财务记账应用，主要功能包括：

1. **用户管理** - 用户注册、登录、角色管理
2. **收支记录** - 记录日常收入和支出
3. **分类管理** - 支出/收入分类管理
4. **客户管理** - 商户客户的应收账款管理
5. **供应商管理** - 供应商的应付账款管理
6. **数据统计** - 月度/年度财务报表

---

## 数据库设计原则

1. **第三范式 (3NF)** - 消除数据冗余
2. **主键设计** - 使用自增ID作为主键，业务ID作为唯一标识
3. **索引设计** - 为常用查询字段建立索引
4. **软删除** - 使用 `deleted_at` 字段标记删除，便于数据恢复
5. **时间戳** - 所有表包含 `created_at` 和 `updated_at` 字段

## 使用说明

### 初始化数据库
```bash

```

### 导入初始数据
```bash
mysql -u root -p < scripts/seed_data.sql
```

### 清理数据（慎用）
```bash
mysql -u root -p < scripts/clean_data.sql
```
