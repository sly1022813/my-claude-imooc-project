## 1. 产品概述

### 1.1 产品背景

个体户和小微企业在日常经营中面临诸多财务管理挑战：进货成本记录、客户付款跟踪、月末收支核对等。传统的Excel表格操作繁琐，付费财务软件又成本高昂。而普通个人用户也需要一款简单好用的记账工具来管理个人收支。

我们需要一款**零门槛、跨设备、无需下载**的网页端财务工具，让每个人都能轻松管理自己的钱袋子。

### 1.2 产品定义

**产品名称**：轻记账

**产品形态**：Web网页应用（H5），支持手机浏览器直接访问

**一句话描述**：一款专为个体户、小微企业和个人设计的轻量级财务管理系统，支持手机浏览器即开即用，让收支记录和生意分析变得简单。

### 1.3 目标用户

| 用户群体 | 特征 | 核心诉求 |
|---------|------|---------|
| 个体户 | 餐饮/零售/服务行业老板 | 记录进货、销售、客户欠款，快速了解生意状况 |
| 小微企业主 | 3-10人公司 | 简化财务记录，月底快速统计收支 |
| 个人用户 | 全年龄段 | 记录日常消费，掌控个人财务 |

**用户痛点分析**：

| 痛点 | 描述 |
|-----|------|
| 不会用复杂软件 | 传统财务软件学习成本高，功能冗余 |
| 多设备访问 | 在店里用电脑记账，外出时无法查看 |
| 数据不安全 | Excel容易丢失，手机App换机数据丢失 |
| 不清楚生意状况 | 不知道这个月赚了还是亏了 |

### 1.4 核心价值主张

- **即用**：打开浏览器就能用，无需下载安装
- **同步**：云端数据自动同步，换设备也不丢失
- **清晰**：收支一目了然，生意状况随时掌握
- **免费**：基础功能永久免费，无隐藏收费

## 4. 功能详细说明

### 4.1 认证模块

#### 4.1.1 注册

**输入字段**：

| 字段 | 类型 | 说明 | 必填 |
|------|------|------|------|
| 手机号 | 手机号 | 用于登录和找回密码 | 是 |
| 验证码 | 短信验证码 | 6位数字 | 是 |
| 密码 | 密码 | 8-20位字母数字组合 | 是 |
| 用户类型 | 选择 | 个人用户 / 个体户 / 企业 | 是 |

**交互流程**：
```
输入手机号 → 点击获取验证码 → 输入验证码 → 设置密码 → 选择用户类型 → 注册成功
```

#### 4.1.2 登录

**方式**：
- 手机号 + 密码
- 手机号 + 短信验证码（免密码）

#### 4.1.3 找回密码

**流程**：
```
输入手机号 → 获取验证码 → 验证通过 → 设置新密码 → 完成
```

### 4.3 记支出

**功能描述**：记录每一笔支出，支持快捷操作。

**输入字段**：

| 字段 | 类型 | 说明 | 必填 |
|------|------|------|------|
| 金额 | 数字键盘 | 支持小数，单位元 | 是 |
| 分类 | 选择器 | 预设分类 + 自定义 | 是 |
| 日期 | 日期选择 | 默认为当天 | 否 |
| 付款方式 | 选择 | 现金/微信/支付宝/银行卡/其他 | 否 |
| 对方单位 | 文本 | 供应商/商户名称 | 否 |
| 备注 | 文本 | 最多200字 | 否 |
| 关联供应商 | 选择器 | 从供应商列表选择 | 否 |

**预设支出分类**：

| 分类 | 图标 | 适用场景 |
|------|------|---------|
| 进货成本 | 📦 | 商品进货、原材料采购 |
| 房租水电 | 🏠 | 房租、水电费、物业费 |
| 工资 | 👥 | 员工工资、兼职费用 |
| 运营费用 | 📋 | 营销推广、包装物料 |
| 餐饮成本 | 🍜 | 餐饮业原材料 |
| 交通物流 | 🚚 | 运费、油费、打车 |
| 办公用品 | 📎 | 打印、文具、设备维修 |
| 税费 | 📄 | 税金、手续费 |
| 社交应酬 | 🍺 | 请客、送礼 |
| 其他支出 | 📌 | 其他支出 |

**快捷操作**：
- 快捷金额：50/100/200/500/1000 滑动选择
- 复制上次：快速复制上一笔记账内容
- 常用组合：保存常用的金额+分类组合

**操作流程**：
```
首页点击「记支出」→ 输入金额 → 选择分类 → 可选填更多信息 → 点击「保存」
```

### 4.4 记收入

**功能描述**：记录每一笔收入，特别适合商户记录营收和客户付款。

**输入字段**：

| 字段 | 类型 | 说明 | 必填 |
|------|------|------|------|
| 金额 | 数字键盘 | 支持小数，单位元 | 是 |
| 分类 | 选择器 | 预设分类 | 是 |
| 日期 | 日期选择 | 默认为当天 | 否 |
| 收款方式 | 选择 | 现金/微信/支付宝/银行卡/转账 | 否 |
| 客户 | 选择器 | 从客户列表选择 | 否 |
| 关联订单 | 选择器 | 关联该客户的未结清欠款 | 否 |
| 备注 | 文本 | 最多200字 | 否 |

**预设收入分类**：

| 分类 | 图标 | 适用场景 |
|------|------|---------|
| 销售收入 | 💰 | 商品销售、服务收费 |
| 服务收入 | 🛠️ | 咨询费、维修费、设计费 |
| 其他收入 | 📌 | 利息、补贴、赔偿 |
| 退款 | ↩️ | 退款（金额显示为负） |

**特殊功能**：
- **关联欠款**：选择客户后，自动显示该客户未结清的欠款，可一键标记为已结清
- **收讫确认**：对于赊账客户收款，明确标记为"收讫"

### 4.5 收支记录列表

**功能描述**：展示所有收支记录的流水账，支持多维度筛选。

**页面元素**：
- 顶部筛选栏
- 收支切换（全部/支出/收入）
- 时间筛选（今日/本周/本月/自定义）
- 分类筛选
- 收支列表（按日期分组）
- 每个分组显示日期和当日小计

**筛选条件组合**：
```
类型：全部 | 支出 | 收入
时间：今日 | 本周 | 本月 | 自定义日期范围
分类：全部分类 | 筛选特定分类
客户/供应商：全部 | 筛选特定对象
关键词：搜索备注内容
```

**列表项显示**：
- 图标 + 分类名称
- 金额（支出红色带-，收入绿色带+）
- 付款/收款方式
- 对方单位/客户名称
- 时间

**交互设计**：
- 左滑单条记录 → 删除/编辑
- 点击单条记录 → 详情页面
- 支持批量选择删除

**空状态**：
- 无记录时显示插画 + "还没有记录，开始记账吧~"

### 4.6 月度统计

**功能描述**：以月份为维度的收支分析页面。

**页面元素**：

| 区域 | 内容 |
|-----|------|
| 月份选择 | 左右滑动切换月份 |
| 核心数据 | 总收入、总支出、净利润（大字） |
| 环比变化 | 与上月对比，↑↓+百分比 |
| 分类占比 | 环形图（支出分类占比） |
| 收支对比 | 收入 vs 支出柱状图 |
| 分类明细 | 分类名称、金额、占比、环比 |

**数据计算**：
```
净利润 = 总收入 - 总支出
环比变化 = (本月 - 上月) / 上月 × 100%
```

**图表设计**：
- 支出分类占比：环形图 + 图例（按金额降序）
- 月度收支对比：双柱状图（收入绿色，支出红色）

### 4.7 收支趋势

**功能描述**：以时间为维度的收支趋势可视化。

**页面元素**：
- 时间维度切换（7天/30天/季度）
- 收支总额折线图
- 收支分类堆叠柱状图
- 最高/最低消费日标注
- 周均/日均消费标注

### 4.8 客户管理

**功能描述**：管理客户信息，跟踪客户欠款（适用于有赊账业务的商户）。

**客户信息**：

| 字段 | 类型 | 说明 |
|------|------|------|
| 客户名称 | 文本 | 必填 |
| 联系方式 | 手机号 | 选填 |
| 地址 | 文本 | 选填 |
| 备注 | 文本 | 选填 |
| 累计交易 | 自动计算 | 显示该客户累计收入 |

**客户账本**：
- 列出该客户所有交易记录
- 显示当前欠款余额
- 支持标记欠款已结清

**欠款提醒**：
- 首页显示欠款超过30天的客户
- 支持筛选所有未结清欠款

### 4.9 供应商管理

**功能描述**：管理供应商信息，跟踪进货记录（适用于有进货业务的商户）。

**供应商信息**：

| 字段 | 类型 | 说明 |
|------|------|------|
| 供应商名称 | 文本 | 必填 |
| 联系方式 | 手机号 | 选填 |
| 主营商品 | 文本 | 选填 |
| 备注 | 文本 | 选填 |
| 累计采购 | 自动计算 | 显示该供应商累计支出 |

### 4.10 分类管理

**功能描述**：管理收支分类，支持自定义添加/编辑/删除。

**功能点**：
- 查看所有分类
- 添加新分类（名称 + 图标 + 颜色）
- 编辑现有分类
- 删除分类（需确认，关联记录转移至"其他"）
- 排序分类（拖拽调整顺序）
- 常驻分类不可删除（进货成本、餐饮成本等核心分类）

### 4.11 数据导出

**功能描述**：将收支记录导出为标准格式，便于用户做进一步分析或报税。

**导出格式**：
- CSV（兼容Excel）
- Excel（.xlsx，格式更规范）

**导出内容**：

| 字段 | 说明 |
|-----|------|
| 日期 | 交易日期 |
| 类型 | 收入/支出 |
| 分类 | 收支分类 |
| 金额 | 交易金额 |
| 付款方式 | 支付方式 |
| 对方 | 客户/供应商名称 |
| 备注 | 交易备注 |

**导出选项**：
- 时间范围选择
- 收支类型选择
- 分类筛选

### 4.12 账户与设置

**个人设置**：
- 修改登录密码
- 修改手机号
- 切换主题（浅色/深色/跟随系统）
- 字体大小调整

**商户设置**：
- 商户名称
- 商户类型（个体户/企业）
- 所属行业
-  Logo上传（可选）

**数据管理**：
- 数据备份（导出全部数据）
- 数据恢复（导入备份）
- 清除所有数据（需二次确认）

## 6. UI/UX设计规范

### 6.1 设计原则

1. **极简**：核心功能一目了然，不需要的功能不展示
2. **高效**：3步内完成任何操作
3. **专业**：符合商业场景的视觉语言
4. **可信赖**：让用户放心地把财务数据交给我们

### 6.2 色彩系统

**主色调**：
- 主色：#2563EB（专业蓝）
- 辅助色：#7C3AED（活力紫）

**功能色**：
- 收入/盈利：#10B981（生机绿）
- 支出/亏损：#EF4444（警示红）
- 待收款：#F59E0B（提醒橙）
- 文字主色：#1F2937
- 文字次色：#6B7280
- 文字弱色：#9CA3AF
- 背景色：#F9FAFB
- 卡片色：#FFFFFF
- 边框色：#E5E7EB

### 6.3 字体规范

- 标题：系统字体 Bold，18-24pt
- 正文：系统字体 Regular，14-16pt
- 金额数字：等宽字体 SemiBold，20-36pt
- 说明文字：系统字体 Regular，12-14pt

### 6.4 间距规范

- 页面边距：16pt
- 卡片内边距：16pt
- 元素间距：8pt / 12pt / 16pt / 24pt
- 圆角：8pt（卡片）、6pt（按钮）、50%（头像）

### 6.5 动效规范

- 页面切换：250ms ease-out 滑入
- 按钮点击：80ms scale(0.96) 回弹
- 列表加载：100ms fade-in 依次
- 数字变化：300ms 数字滚动
- Toast提示：200ms fade-in，自动消失

## 8. 验收标准

### 8.1 MVP验收清单

| 功能 | 验收条件 |
|-----|---------|
| 注册登录 | 手机号+验证码可完成注册和登录 |
| 记支出 | 输入金额→选分类→保存，步骤≤3步 |
| 记收入 | 输入金额→选分类→保存，步骤≤3步 |
| 收支列表 | 能按日期倒序展示所有记录，支持筛选 |
| 月度统计 | 显示当月总收入、总支出、净利润和分类占比 |
| 数据持久化 | 关闭浏览器后重新打开数据不丢失 |

### 8.2 体验验收清单

| 指标 | 验收条件 |
|-----|---------|
| 首次使用 | 新用户能在1分钟内完成注册并记录第一笔 |
| 响应速度 | 记账操作后500ms内看到结果 |
| 视觉一致性 | 所有页面符合色彩和间距规范 |
| 错误处理 | 操作失败有友好提示，不出现空白页面 |

```

id, user_id, name, phone, products, remark, created_at
```
